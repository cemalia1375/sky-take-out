# 📦 极光外卖（AI增强版）

## 📌 项目简介
本项目基于黑马程序员《苍穹外卖》课程进行完整复刻，并在其基础上进行了深度功能扩展。核心目标是解决**高并发场景下的数据一致性问题**，并引入 **AI 智能助手模块**，实现“高并发架构 + AI 业务系统”的融合应用。

系统包含** 管理端 + 用户端（微信小程序）**，针对下单、库存、优惠券等高频交互场景引入了商业级解决方案。

### 🛡️ 高并发保障机制（核心进阶 ⭐）
针对核心下单链路进行了重构，通过了 100线程并发压测 验证：

- **Redisson 分布式锁**

  替换手写锁逻辑，解决重复下单、高频催单的排他性问题。

  利用“看门狗”机制保障业务长耗时下的锁安全，防止锁提前释放导致的一致性风险。

- **LUA 原子扣减机制**

  编写 LUA 脚本实现多商品库存的原子性校验与扣减，彻底解决秒杀场景下的超卖问题。

- **双重资源回滚逻辑**

  严谨的 try-catch-finally 结构：捕获业务异常并触发 Redis 库存异步回滚，保障内存与数据库的最终一致性。

- **分布式优惠券保护**

  针对“并发抢券”场景设计专用分布式锁，防止同一张优惠券被多个瞬时订单非法套用。

- **Redisson 延迟队列 (RDelayedQueue)**

  实现订单超时自动取消：替代传统定时任务扫表方案，分钟级精准判定，降低系统 80% 的扫描开销并自动释放锁定资源。

> ❗ 未实现功能：数据导出（Excel）

# 🤖 AI 业务助手系统

## 🧠 核心设计亮点

### 🔹 AI + 业务系统融合架构
- **本地业务优先**：优先执行数据库查询
- **AI 兜底与增强**：AI 作为补充能力，处理复杂场景
- **效率优化**：提高系统响应效率，减少无效模型调用

### 🔹 流式响应优化（SSE）
- 使用 `SseEmitter` 实现流式输出
- 前端逐字渲染（打字机效果）
- 显著提升用户体验

### 🔹 多轮对话上下文管理
- 数据库存储聊天记录
- 加载最近对话（防止 Token 溢出）
- 支持上下文连续对话

### 🔹 自然语言转业务查询

**实现"伪 NL2SQL"能力：**

|------|------|
| 关键词识别 | 识别"订单"、"未完成"等业务关键词 |
| 正则提取 | 提取订单号等关键信息 |
| 自动映射 | 映射到后端业务接口 |

↓

↓
