# 📦 极光外卖（AI增强版）

## 📌 项目简介
本项目基于黑马程序员《苍穹外卖》课程进行完整复刻，并在原有餐饮业务系统的基础上进行功能扩展与优化，重点引入 **AI 智能助手模块**，实现“AI + 业务系统”的融合应用。

系统包含 **管理端 + 用户端（微信小程序）**，实现从菜品管理、下单支付到订单处理的完整业务闭环，同时通过接入通义大模型，提升系统交互智能化水平。

---

- 管理端（含小助手）：http://localhost:8888/#/assistant

### 后端

- MySQL

- 阿里云通义千问（Qwen-Plus）
- 多轮对话（上下文记忆）
- Prompt 工程（System Prompt 设计）
- 流式输出（打字机效果）

### 🤖 AI 智能助手（项目亮点 ⭐）

在管理端新增“小助手”模块，实现自然语言驱动的业务查询：

#### ✅ 支持能力
- 查询最近订单
- 查询未完成订单
- 根据订单号查询订单

#### ✅ 技术实现
- **SSE 流式输出**
  - 使用 `SseEmitter` 实现流式返回
  - 支持前端打字机效果
- **上下文记忆**
  - 基于数据库存储聊天记录
  - 自动加载最近历史对话
- **关键词识别**
  - 如：“订单”“未完成”等触发业务逻辑
- **正则解析**
  - 自动提取用户输入中的订单号
- **AI + 业务融合**
  - 优先走本地数据库查询
  - 未命中再调用大模型生成回复

# 🤖 AI 业务助手系统

## 🧠 核心设计亮点

### 🔹 AI + 业务系统融合架构
- **本地业务优先**：优先执行数据库查询
- **AI 兜底与增强**：AI 作为补充能力，处理复杂场景
- **效率优化**：提高系统响应效率，减少无效模型调用

### 🔹 流式响应优化（SSE）
- 使用 `SseEmitter` 实现流式输出
- 前端逐字渲染（打字机效果）
- 显著提升用户体验

### 🔹 多轮对话上下文管理
- 数据库存储聊天记录
- 加载最近对话（防止 Token 溢出）
- 支持上下文连续对话

### 🔹 自然语言转业务查询

**实现"伪 NL2SQL"能力：**

| 能力 | 说明 |
|------|------|
| 关键词识别 | 识别"订单"、"未完成"等业务关键词 |
| 正则提取 | 提取订单号等关键信息 |
| 自动映射 | 映射到后端业务接口 |
```bash
处理流程示例：
用户输入：查询订单1774439386930
↓
提取订单号 1774439386930
↓
查询数据库
↓
返回结构化结果
```
